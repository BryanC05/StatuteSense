# ⚖️ StatuteSense — Ace Attorney Legal AI Courtroom Platform

**StatuteSense** is an AI-powered legal document analysis and courtroom intelligence platform built with Next.js, styled in a high-impact **Courtroom Command Desk** theme (zero trademarked text policy).

---

## 🚀 Key Features & Capabilities

- ⚖️ **Defense Command Desk**: Document text & PDF analysis with governing jurisdiction selector and AI disclaimers.
- ⚡ **"OBJECTION!" Contradiction Detector**: Scans contracts for internal term clashes (e.g. term vs survival, liability cap vs indemnity) with 3D objection banners.
- ⚔️ **Defense Clause Redline Rewriter**: Generates 3 tailored defense rewrites (*Balanced*, *Strong Defense*, *Compromise Fallback*) for aggressive clauses.
- 📜 **Multi-Jurisdiction Selector**: Aligns legal analysis with **US Federal**, **California (UTSA & CCPA)**, **New York**, **Delaware**, **EU/GDPR**, or **UK Common Law**.
- 🏛️ **Jury-Friendly Plain English Translator**: Translates dense legalese into 8th-grade level executive summaries for non-lawyers.
- 💬 **Case Follow-Up Interrogations**: Interactive cross-examination chat with loaded document context and 1-click interrogation prompt chips.
- 📄 **Official Court Brief PDF Exporter**: One-click generation of printable court docket reports.
- 📁 **Batch Evidence Portfolio Analyzer**: Upload multiple contracts simultaneously for parallel analysis across a portfolio matrix.
- 🔍 **RAG Vector Store JSON Legal Schema**: Automatically appends structured JSON Legal Schemas to outputs for RAG vector databases.
- 📜 **Anti-Hallucination Legal Citation Engine**: Grounded strictly in verified statutes (DTSA, UTSA, Restatement (Second) of Contracts § 71/75) and landmark case law (E.I. du Pont, Rockwell, Silvaco Data Systems).

## 💻 Local Setup

1. Copy `.env.example` to `.env.local`
2. Add your Hugging Face Router / LLM API keys:
   ```env
   HUGGINGFACE_API_KEY=your_key_here
   HUGGINGFACE_MODEL=Qwen/Qwen2.5-72B-Instruct
   ```
3. Install dependencies and start local dev server:
   ```bash
   npm install
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
